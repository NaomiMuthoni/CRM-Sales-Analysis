CRM Sales Performance & Pipeline Analytics

PROJECT OVERVIEW

This project analyses CRM sales pipeline data using Microsoft Excel and Power BI to understand sales performance, revenue generation, and deal outcomes.

Business Questions
1. How many sales opportunities are recorded?
2. Which products generate the most revenue?
3. Which sales agents generate the most revenue?
4. What is the win rate?
5. What should management investigate next?

Tools Used
1. Excel
2. Power BI
3. Dax
